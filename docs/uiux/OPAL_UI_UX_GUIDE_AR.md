# دليل OPAL UI/UX المعتمد

هذا الدليل هو المرجع الإلزامي لأي تعديل واجهة لاحق في OPAL ERP.

## المبادئ

1. كل وظيفة لها موضع رسمي واحد، ولا تكرر الروابط أو الأزرار بلا حاجة تشغيلية.
2. كل معلومة تظهر مرة واحدة في السياق الأنسب لها.
3. جميع الصفحات تحافظ على RTL، وسهولة القراءة، والاستجابة للهاتف والتابلت والويب.
4. لا يغيّر تحسين الواجهة Models أو قاعدة البيانات أو الصلاحيات أو مسارات العمل.
5. يبقى `students.Student` نموذج الطالب الرسمي الوحيد.

## الهيكل القياسي للصفحة

العنوان والوصف المختصر، ثم الإجراءات، ثم البحث والفلاتر، ثم المؤشرات، ثم المحتوى أو الجدول، ثم الترقيم والطباعة والتصدير عند الحاجة.

## الهوية البصرية

- الأزرق الداكن والدرجات المحايدة أساس الهوية.
- الذهبي للأحداث والتنبيهات المهمة.
- الأخضر للنجاح والسداد الكامل.
- الأصفر للتحذير والحالات الجزئية.
- الأحمر للأخطاء والغياب والاستحقاقات الحرجة.
- التأثير الزجاجي الكريستالي خفيف ولا يضعف القراءة أو الأداء.

## المكونات المعتمدة

- Sidebar وTopbar موحدان.
- البطاقات والجداول والنماذج والتنبيهات والنوافذ تتبع طبقات CSS المركزية.
- صفحات Student 360 وParent 360 وTeacher 360 تتبع بنية بصرية واحدة.
- لا تضاف ملفات CSS متفرقة لقسم واحد قبل التحقق من إمكانية توسيع الطبقات المركزية.

## الاستجابة والوصول

- لا تمرير أفقي للصفحة نفسها.
- الجداول الكبيرة تمرر داخل حاويتها فقط.
- أهداف اللمس والأزرار والحقول مناسبة للهاتف.
- النصوص لا تُقص ولا تغطي عناصر التحكم.
- الطباعة تخفي عناصر التنقل والإجراءات غير اللازمة.

## قواعد التطوير

قبل اعتماد أي تعديل واجهة: فحص القوالب، `python manage.py check`، فحص عدم وجود migrations غير مقصودة، تشغيل `python manage.py audit_opal_uiux`، ثم اختبار المسارات الرئيسية على أكثر من حجم شاشة.
