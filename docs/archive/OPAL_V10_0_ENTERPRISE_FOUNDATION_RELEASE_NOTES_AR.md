# OPAL ERP V10.0 — Enterprise Foundation

## ما تم بناؤه

- محرك طلبات وسير عمل عام للطلبات المدرسية.
- مركز موافقات مع الاعتماد والرفض والإعادة والأرشفة والتعليقات.
- سجل زمني كامل لكل إجراء على الطلب.
- مركز إشعارات داخل النظام مع حالة مقروء/غير مقروء.
- إشعارات تلقائية عند إنشاء الطلب أو تغيير حالته.
- سجل تدقيق للعمليات وتسجيل الدخول والخروج والتصدير.
- لوحة تشغيل مؤسسي بمؤشرات الطلبات والإشعارات والحضور والمتابعة.
- مركز تقارير موحد للطلاب والرسوم والتحصيل والحضور والأكاديمي والوثائق والطلبات.
- تصدير CSV متوافق مع Excel.
- روابط منفصلة حسب الدور في القائمة الجانبية.
- لا توجد أي محاسبة عامة أو دفتر يومية أو دفتر أستاذ.

## قواعد معمارية محفوظة

- النموذج الرسمي الوحيد للطالب هو `students.Student`.
- الجانب المالي محصور في الرسوم والدفعات والإيصالات والمتبقي.
- الحفاظ على OPAL Design System.
