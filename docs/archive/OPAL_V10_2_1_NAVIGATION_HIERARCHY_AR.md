# OPAL ERP V10.2.1 — Navigation Hierarchy

## المبدأ
- القائمة الجانبية: الوحدات الرئيسية فقط.
- الصفحة الرئيسية للوحدة: جميع الروابط الفرعية والعمليات المرتبطة بها.
- لا حذف للوظائف أو المسارات.
- عدم تكرار روابط ولي الأمر في كل صفحة؛ تظهر في الصفحة الرئيسية للبوابة فقط.

## الوحدات الرئيسية للإدارة
1. لوحة التحكم
2. إدارة الطلاب
3. الشؤون الأكاديمية
4. الرسوم المدرسية
5. التشغيل المؤسسي
6. تكامل OpenEMIS
7. مركز التطوير
8. إعدادات النظام

## الروابط الفرعية
- إدارة الطلاب: التسجيل، سجل التسجيل، أولياء الأمور، الوثائق.
- الشؤون الأكاديمية: الصفوف، الشعب، الأعوام، المواد، الخطة، الحضور، الامتحانات، المعلمون.
- الرسوم المدرسية: الفواتير، إضافة فاتورة، تسجيل دفعة، الإيصالات، أرشيف دفعات التسجيل.
- التشغيل المؤسسي: الطلبات، الإشعارات، التقارير، سجل العمليات، الصلاحيات.
- OpenEMIS: الإعدادات، اختبار الاتصال، سجل المزامنة.
- مركز التطوير: اللوحة التنفيذية، الوحدات، المهام، خارطة الطريق، الإصدارات، الأخطاء، تقرير المشروع.
