# قائمة اعتماد OPAL ERP للتشغيل

لا يُعلن النظام جاهزًا للتشغيل الفعلي إلا بعد نجاح البنود التالية على PythonAnywhere:

1. `python manage.py check` دون أخطاء.
2. `python manage.py makemigrations --check --dry-run` يعرض `No changes detected`.
3. `python manage.py migrate --noinput` يكتمل بنجاح.
4. `python manage.py test` تنجح جميع الاختبارات.
5. `python manage.py verify_core_readiness` لا يعرض أخطاء حرجة.
6. فحص تسجيل طالب كامل وربطه بالأسرة.
7. فحص فاتورة ودفعة وإيصال وكشف أسرة.
8. فحص الأقساط والخصومات والموافقة عليها.
9. فحص قيد الطالب والنقل والترفيع والانسحاب وإعادة القيد.
10. فحص الجدول ومنع التعارض.
11. فحص الحضور والتعديل والإقفال.
12. فحص الامتحان والعلامات والاعتماد والنشر والقفل.
13. التأكد أن ولي الأمر لا يرى نتيجة غير منشورة.
14. فحص إصدار وثيقة وإلغائها وإعادة إصدارها والتحقق منها.
15. فحص أدوار المدير والمعلم وولي الأمر كلٌ بحسابه.
16. حفظ النسخة الناجحة على GitHub.

تكامل OpenEMIS الحقيقي بند خارجي مؤجل لحين توفير بيانات الوزارة الرسمية، ولا يدخل في قرار تشغيل النواة المدرسية داخليًا.
