# OPAL ERP V6 Foundation Pack

## المنجز
- إنشاء حساب مستخدم للمعلم من ملفه الإداري.
- توليد اسم مستخدم فريد وكلمة مرور مؤقتة قوية.
- ربط الحساب تلقائيًا بالمعلم.
- إنشاء/تحديث ملف المستخدم وربطه بدور المعلم والمدرسة والفرع.
- إضافة الحساب إلى مجموعة Teachers.
- إعادة تعيين كلمة مرور المعلم من لوحة الإدارة.
- عرض بيانات الدخول مرة واحدة مع خيار الطباعة.
- منع حساب المعلم من الوصول إلى صفحات الإدارة أو المحاسبة وإعادته إلى بوابته.
- استمرار حماية بوابة المعلم على مستوى Views.

## ملاحظات
- لا توجد Migration جديدة.
- لم يتم تعديل نموذج الطالب الرسمي students.Student.
- قاعدة البيانات وmedia غير مضمنتَين في حزمة المصدر.
