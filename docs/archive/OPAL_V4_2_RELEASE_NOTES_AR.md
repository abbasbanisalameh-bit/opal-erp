# OPAL ERP V4.2

## المضمن في الإصدار
- إخفاء روابط الإدارة عن ولي الأمر، مع بقاء الحماية الفعلية للمسارات.
- توجيه رابط أولياء الأمور للموظفين إلى صفحة الإدارة `/parent/manage/`.
- وحدة إدارة المعلمين: لوحة مؤشرات، قائمة وبحث، إضافة وتعديل، تفعيل وإيقاف، ملف معلم، تكليفات المواد والشعب، وعرض الجدول المرتبط.
- حماية وحدة المعلمين بصلاحية الموظف/المدير.
- الحفاظ على النماذج الحالية دون إنشاء نموذج طالب جديد ودون تغييرات قاعدة بيانات جديدة.
