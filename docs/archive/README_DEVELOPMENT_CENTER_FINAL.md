# Development Center v1.0 Final

هذه الحزمة مبنية على النسخة التي تم رفعها من مركز التطوير، وتحتوي على تحسينات مركزة:

- محرك سير عمل أكثر أمانًا مع منع حلقات الحفظ المتكررة في signals.
- تحديث حالات المهام تلقائيًا حسب نسبة الإنجاز.
- تحديث نسب الوحدات ودورات التطوير والإصدارات عند تشغيل المحرك أو تعديل مهمة.
- رسائل عربية لمحرك سير العمل والإشعارات.
- تعريب نماذج المهام والوحدات والإصدارات والمراحل ودورات التطوير.
- تعريب صفحات مركز التطوير الأساسية.
- إعادة بناء صفحة مخطط جانت بشكل نظيف وبهوية OPAL الداكنة.
- ألوان مخطط جانت حسب حالة المهمة: لم يبدأ، قيد التنفيذ، قيد المراجعة، مكتملة، متأخرة.
