# OPAL ERP V8.0 — Exams & Academic Analytics

## المنجز
- لوحة تحليل مركزية للامتحانات مع فلاتر العام الدراسي والصف والمادة.
- مؤشرات عدد الامتحانات والعلامات ومتوسط النتائج ونسبة النجاح.
- تحليل كل امتحان: الأعلى، الأدنى، المتوسط، نسبة النجاح وتوزيع التقديرات.
- التحقق من العلامات عند الإدخال الجماعي ومنع القيم السالبة أو التي تتجاوز العلامة القصوى.
- تصدير نتائج الامتحان بصيغة CSV المتوافقة مع Excel.
- سجل أكاديمي موحد لكل طالب مع المتوسط حسب المادة والمعدل العام.
- نسخة طباعة مستقلة للسجل الأكاديمي.
- الربط من تفاصيل الامتحان إلى السجل الأكاديمي للطالب.

## ملاحظات
- لا توجد Migrations جديدة.
- يعتمد النظام حصراً على `students.Student` كنموذج الطالب الرسمي.
