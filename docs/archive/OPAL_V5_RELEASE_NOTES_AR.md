# OPAL ERP V5 — Academic Operations & Portals

## المنجز
- إعادة جميع الروابط الفرعية لمركز التطوير للمدير.
- قائمة جانبية منفصلة حسب الدور: إدارة، معلم، ولي أمر.
- بوابة معلم مرتبطة بحساب المستخدم.
- عرض تكليفات وجدول المعلم.
- تسجيل حضور طلاب الشعب المكلف بها المعلم فقط.
- إدخال علامات طلاب الشعب والمواد المكلف بها المعلم فقط.
- إضافة جدول الأبناء داخل بوابة ولي الأمر.
- استمرار عزل ولي الأمر عن أي بيانات خارج أسرته.
- صفحة 403 متوافقة مع هوية OPAL.
- Middleware يمنع المعلم غير الإداري من الوصول لوحدات الإدارة.

## قاعدة البيانات
يوجد Migration جديد:
`teachers/migrations/0003_teacher_user.py`
ويضيف ارتباطًا اختياريًا بين المعلم وحساب المستخدم، دون حذف أو تعديل بيانات المعلمين الحالية.

## ملاحظة الاختبارات
نجح `python manage.py check` و`makemigrations --check --dry-run` و`migrate` على قاعدة المشروع الحالية.
إنشاء قاعدة اختبار نظيفة ما زال يتوقف بسبب Migration تاريخية قديمة تشير إلى `academics.StudentRecord`. هذه المشكلة سابقة لهذا الإصدار ولا تمنع تشغيل قاعدة الموقع الحالية.
