# OPAL ERP — CORE COMPLETE FINAL

## حالة الإصدار

هذا الإصدار هو حزمة الإكمال الوظيفي الأساسية المبنية على النسخة المستقرة V10.3. نطاقه مجمّد على وظائف المدرسة الأساسية فقط، دون إضافة كماليات أو توسعات جمالية خارج الخطة المعتمدة.

## ما أُنجز في الحزمة

### الاستقرار المعماري
- إصلاح سلسلة الترحيلات التاريخية المرتبطة بالنموذج المحذوف `academics.StudentRecord`.
- تثبيت `students.Student` كنموذج الطالب الرسمي والوحيد.
- توحيد العام الدراسي على `core.AcademicYear` وإزالة الاعتماد التشغيلي على النموذج الأكاديمي القديم.
- إضافة ترحيلات بيانات آمنة للتكليفات، والخطة الدراسية، والجدول، والفواتير، والوثائق.
- ضمان نجاح إنشاء قاعدة بيانات جديدة من الصفر.
- إزالة التطبيقات القديمة الفارغة من التطبيقات المثبتة دون المساس بالتطبيقات الفعلية.

### الأعوام والفصول والهيكل الأكاديمي
- ضبط عام دراسي حالي واحد لكل مدرسة.
- ضبط فصل دراسي حالي واحد لكل عام.
- التحقق من أن تواريخ الفصل تقع داخل العام الدراسي.
- واجهات إدارة الأعوام والفصول والصفوف والشعب والمواد.
- قيود سعة الشعب واتساق القيد مع العام والصف والشعبة.

### حركة الطالب
- الترفيع، والنقل، والانسحاب، وإعادة القيد، والتخرج، وتغيير الشعبة.
- إغلاق القيد السابق وإنشاء القيد الجديد بصورة مترابطة.
- سجل مستقل لكل حركة طلابية.
- ترفيع جماعي مع التحقق من السعة.

### الجدول الدراسي
- إدارة الحصص الزمنية وإدخالات الجدول.
- منع تعارض المعلم والشعبة والغرفة في الوقت نفسه.
- التحقق من توافق تكليف المعلم مع المادة والشعبة.
- لوحات عرض وطباعة للجدول.

### الحضور
- تسجيل وتعديل الحضور والتأخر والغياب بعذر.
- أوقات الوصول والمغادرة وسبب العذر.
- إقفال كشف الحضور بعد اعتماده.
- حفظ المستخدم الذي سجل أو عدّل الحضور.
- تقارير الحضور وإشعارات ولي الأمر.

### الامتحانات والنتائج
- ربط الامتحان بالعام والفصل الدراسي.
- حالات مسار العمل: مسودة، مفتوح، معتمد، منشور، مغلق.
- قفل العلامات بعد الاعتماد.
- اعتماد النتائج ونشرها وإعادة فتحها بصلاحية إدارية.
- عدم إظهار النتائج لولي الأمر قبل النشر.
- كشوف نتائج رسمية مبنية على النتائج المنشورة.

### الرسوم المدرسية
- أرقام فواتير مستقلة وحالات واضحة للفواتير.
- صافي الرسوم بعد الخصم، والمدفوع، والمتبقي، والمتأخر.
- الأقساط وتواريخ الاستحقاق.
- طلبات الخصم والموافقة عليها من مسار الطلبات.
- منع الدفع الزائد.
- عكس الدفعات وإلغاء الإيصالات مع بيانات تدقيق.
- كشوف الطالب والأسرة والتقارير المدرسية دون أي محاسبة عامة.

### الوثائق
- رمز تحقق فريد لكل وثيقة.
- صفحة تحقق عامة.
- إلغاء الوثيقة وإعادة إصدارها وربط النسخة البديلة.
- حفظ سبب الإلغاء والمستخدم والتاريخ.

### التشغيل المؤسسي والصلاحيات
- أنواع طلبات مرتبطة بالعمليات المدرسية الأساسية.
- التحقق من انتقالات حالات الطلب.
- ربط قرارات الخصم بمسار الموافقة.
- إشعارات وسجل عمليات وتقارير محدثة.
- توسيع مصفوفة الصلاحيات لتغطية الوظائف الجديدة.

### فحص الجاهزية
أضيف الأمر:

```bash
python manage.py verify_core_readiness
```

ويفحص الأعوام والفصول، وسعة الشعب، واتساق القيود، والفواتير والدفعات، وقفل الامتحانات، والوثائق الملغاة، وتعارضات الجدول.
