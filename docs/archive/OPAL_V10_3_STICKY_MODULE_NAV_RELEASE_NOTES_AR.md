# OPAL ERP V10.3 — Unified Sticky Module Navigation

## الهدف
الإبقاء على رابط رئيسي واحد لكل وحدة في القائمة الجانبية، ونقل روابط الوحدة الفرعية إلى شريط أزرار موحد وثابت أعلى محتوى الصفحة.

## ما تم
- إضافة شريط فرعي مشترك يظهر تلقائيًا في جميع صفحات الوحدة.
- يبقى الشريط ظاهرًا أثناء التمرير، ويظهر في كل صفحة فرعية بنفس الشكل والترتيب.
- تمييز الزر النشط تلقائيًا.
- تمرير أفقي لطيف عند كثرة الأزرار أو على الهاتف.
- توحيد الحجم والأيقونات والحواف مع OPAL Design System.
- تنظيم وحدات: الطلاب، الأكاديمي، الرسوم، التشغيل المؤسسي، OpenEMIS، ومركز التطوير.
- الإبقاء على أزرار الإجراءات السياقية داخل الصفحات مثل إضافة طالب أو حفظ أو طباعة.
- إزالة بطاقات وروابط التنقل المكررة من الصفحات الرئيسية ذات الصلة.

## الفحص المنفذ
- `python manage.py check`: ناجح.
- `python manage.py makemigrations --check --dry-run`: لا تغييرات.
- تحميل وتجميع القوالب المعدلة: ناجح.
- اختبار عكس روابط Django في جميع أشرطة الوحدات: ناجح.

لا يوجد تعديل على قاعدة البيانات أو نماذج الطلاب أو منطق الرسوم.
