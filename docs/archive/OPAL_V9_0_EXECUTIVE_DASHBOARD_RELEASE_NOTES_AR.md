# OPAL ERP V9.0 — Executive Dashboard & Management Intelligence

## المنجز
- تحويل الصفحة الرئيسية إلى لوحة إدارة تنفيذية.
- مؤشرات الطلاب والمعلمين والشعب والحضور والمالية والامتحانات والوثائق.
- نسبة التحصيل والمستحقات والفواتير المتأخرة.
- نسبة النجاح ومتوسط العلامات.
- اتجاه الحضور خلال سبعة أيام.
- قائمة متابعة مالية وحضور للطلاب الأعلى مخاطرة.
- تصدير ملخص الإدارة إلى CSV متوافق مع Excel.
- قصر لوحة الإدارة على المستخدمين الإداريين.

## قاعدة البيانات
لا توجد migrations جديدة.
