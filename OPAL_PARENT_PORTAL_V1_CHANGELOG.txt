OPAL ERP - تحديث بوابة أولياء الأمور V1

تم إنجازه في هذا التحديث:
1. توسيع بوابة ولي الأمر إلى صفحات كاملة:
   - الرئيسية
   - الأبناء
   - الرسوم والإيصالات
   - الحضور
   - النتائج
   - الوثائق
   - الإعلانات
   - الحساب وتغيير كلمة المرور
2. ربط البوابة بحساب ولي الأمر والأسرة Family و FamilyStudent.
3. ضمان أن ولي الأمر لا يرى إلا أبناءه المرتبطين بحسابه.
4. عرض كشف مالي مجمع لكل الأبناء وإيصالات الدفعات.
5. عرض الحضور، النتائج، الوثائق، والإعلانات.
6. إضافة أمر إدارة لإنشاء/تحديث حسابات أولياء الأمور وربط الأبناء الحاليين:
   python manage.py sync_parent_accounts --dry-run
   python manage.py sync_parent_accounts
7. المحافظة على نموذج الطالب الرسمي students.Student فقط.
8. بدون تعديل قاعدة البيانات داخل ملف التحديث وبدون media.

ملاحظات:
- هذا تحديث كود فقط، يركب فوق مشروعك الحالي.
- يجب تشغيل الأمر بعد التركيب لربط الطلاب الحاليين بحسابات أولياء الأمور.
